# Day 283 — Error & Slavery (Contemporary Parallel)

## Frame

Q.51–52 treat two diriment impediments: **error** and **condition of servitude**. Aquinas's key distinction in the matter of error is precise — error about a mere *quality* of the partner (wealth, status) does not void consent, but error about the *person* (you consent to marry A and are given B), or error about a condition that touches the very identity to which one consented, does void it, because consent was directed at someone other than the one received. The servitude question asks whether marrying a person one wrongly believed free (when they are in fact bound) voids consent — Aquinas treats unknown servile condition as an error that can void, since it changes the partner one took oneself to be joining. (The slavery framing is a historical artifact of the text's social world, not a contemporary endorsement.) The contemporary version: **what fixes the *identity* of the agent one couples with, and what kind of mismatch between one's model of that agent and the agent received is sufficient to void the coupling?**

## Problem

The shared inquiry-problem is **identity-tracking across an interface, and the limits of perspective it exposes**. Aquinas needs a line between errors that touch *who* the partner is (voiding) and errors that touch only *how* the partner is (non-voiding). The contemporary sciences of perception and agency face the same: each agent meets the other only through an interface, never directly; consent is given to a *model* of the other; and the question is which model-to-reality mismatches break the coupling versus which are tolerable error the union can absorb.

## Resource

The Hoffman-tradition program supplies the leading move. Tom's PRS-form record of Hoffman's work (PRS-03 in the Hoffman-tradition wiki, *perception as a fitness-tracking interface*; PRS-10, *trace blankets subsume Markov blankets*) holds that agents never access one another's reality, only interface icons — so consent is always given to an *iconic model* of the partner, never to the partner-in-themselves. This reframes Aquinas's distinction: an error of *quality* is a wrong value on an attribute of the icon (tolerable; the icon still points at the right referent), whereas an error of *person* is a referent failure — the icon pointed at the wrong agent altogether — and *that* breaks the coupling because the two never in fact addressed each other. The Kastrup-tradition program supplies the metaphysics of identity that grounds "the person": PRS-02 (*individual identity within monism*) and PRS-24 (*the indexical problem — why this individual rather than another*) locate personal identity as a real (if soft) dissociative boundary, so that "error of the person" is a failure to couple with the intended *boundary*, not merely with the intended description. Friston's PRS-06 (*mutual modeling*) explains why referent failure voids the unit: coupling requires each model the *other*; if A models B but is coupled to C, no shared blanket forms. Levin's PRS-09 (*cognitive attribution across scales*) supports the qualities-vs-person line by distinguishing an agent's identity from its current properties.

## Solution (proposed, speculative)

The contemporary-parallel response: **error voids consent exactly when it is a referent failure — when the agent one actually couples with is not the agent one's consent addressed — and tolerable error is mis-valued attributes of the right referent.** What it *shares* with Aquinas: the person/quality distinction and the verdict that error-of-person voids. Where it *reframes*: Aquinas locates the line in the *substance* of the person versus accidents; the monist/interface reframe locates it in *reference* — does the model point at the intended agent-boundary? — which has the virtue of explaining marginal cases (an error about a quality so central it changes *who* the person is) as referent-determining attributes rather than as a fuzzy exception. Where evidence is *firm*: that agents transact only through interfaces, never through direct access, is a load-bearing formal claim of interface theory. Where *speculative*: the metaphysics of personal identity as a dissociative boundary is interpretive, and the legal calculus of which errors void is normative, not derivable from the model.

## The central-theme thread

This article is a sharp lesson in the project's founding limitation: we never see one another whole; we consent to icons. Marriage is undertaken across an irreducible epistemic gap, on trust that the icon points truly. That is the central theme's "fear and trembling" at the scale of the marrying pair — loving unity is risked toward a person one cannot fully see, and the impediment of error marks the point where the gap was not narrowed but falsified.

## Bridges

- **Hoffman PRS-03 / PRS-10 (formal / speculative):** consent addresses an iconic model; quality-error = wrong attribute, person-error = referent failure (voids).
- **Kastrup PRS-02 / PRS-24 (metaphysical, speculative):** personal identity as a real dissociative boundary — what "the person" in "error of person" picks out.
- **Friston PRS-06 (formal):** referent failure prevents a shared blanket from forming — why it voids the unit.
- **Levin PRS-09 (empirical/conceptual):** identity vs. current properties — supports the person/quality line.
