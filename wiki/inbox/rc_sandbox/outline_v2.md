2,402 text cells / 138,415 words / 960 rows. Extracted 2026-09-04.
Supersedes v1. Amendments 1-6 agreed by TL 2026-09-04.

Node IDs are stable. `assignments.csv` maps `cell_id -> node_id` plus facets; the reading
document is GENERATED from that table. A misfiling is a one-line fix, not a rewrite.

**Verbatim rule.** Cells are moved and headed, never rewritten, merged, or summarized.
Editorial text is marked as mine.

## Facets carried per cell (not nodes)
- `voice` — whose utterance. Default **Loughran**; non-Loughran only on evidence (~8%).
  `voice_uncertain` flags long cells where quotation is unmarked.
- `about` — figures engaged, 0..n. Requires the initialism table below. This is the names index.
- `discipline` — 0..n. Disciplines CONTRIBUTE AT levels; they are not the structure.
- `work_order` — a note-to-self ("find reference to...", "write the paper..."). Keeps its node.
- `run_id` — consecutive cells in one row sharing a node render as ONE contiguous block in
  original left-to-right order. Question-then-answer and quote-then-reaction pairs must not split.
