How filters work

Each section filters independently.

  • Within a section (e.g. Traditions), checked items are included — select Levin + Hoffman to show both.
  • Across sections (Traditions × Disciplines × Years), a data point must pass every active section simultaneously.
  • Edges only connect two nodes that are both visible (turn off the Edges box to hide them all).
  • Checking everything shows the full dataset. Reset restores that state from anywhere.

Narrative (PRS) Connectome

Each node is an agentic PRS narrative — a small model (problem → resource → solution). Edges wire narratives together: shared threads within a tradition; across traditions, the coils (association fibers). Read it as the emergence of rival master sciences. Axes: angle = discipline, height = year.

Legend key

Problem / Resource / Solution — the three node shapes of one narrative.

Synergistic coil (teal) — a cross-tradition bridge: a shared resource linking programs, placed at its discovery year.

Cross-tradition link (gold) — a finding-driven connection between traditions.

Convergence hub (gold glow) — a resource shared across ≥2 traditions; a candidate master-science seed.

Generative coil (orange →) — one narrative's solution feeding another's resource: the directed spiral.
