The **aggregator** surface resolved it on first attempt, in plain HTML, for free. - **Corollary worth carrying:** the 09-01 run treated the absence of the episode from Listen Notes as evidence against the attribution. It was evidence only about Listen Notes. A single directory's silence is not evidence about the world; check a second directory before drawing an inference from the first.
