  Date searched: 2026-08-18
  Original item: PRESUMPTION-764
  Original statement: Whether a universally-declared, universally-breached budget is a constraint. Risk: Medium.

  Reading challenged: The operative (reassuring) reading — that a budget which every run declares and every run exceeds is nonetheless functioning as a constraint, because the declaration plus disclosure of the breach preserves discipline. This search attacks that reading. The corporate-governance and safety-culture literatures both say that a norm which is universally departed from, with disclosure as the only sanction, converts into a documentation ritual and then into a new baseline.

  Strength of challenge: Strong (mechanism); Moderate (directly-transferable empirical base, since the corporate-governance evidence is about firms and investors, not agent pipelines)

  Summary: The literature gives no support to the idea that a universally-breached budget remains a constraint, and supplies two well-attested mechanisms by which it stops being one. Vaughan's normalization of deviance describes how repeated, documented, consequence-free departure from a specified limit *raises the limit* without anyone deciding to raise it — the deviation is reclassified rather than corrected. The comply-or-explain literature describes the terminal state of a disclosure-only regime: explanations degrade to boilerplate, the intended monitor lacks the incentive or resource to read them, and the regime's own scholars conclude that enforcement, not disclosure, is what makes it bind. The critical diagnostic detail in the item is the word "universally": a limit breached by a minority of runs is a constraint with exceptions; a limit breached by *all* runs is a mis-set parameter that the system has already routed around, and the declaration is the routing. Note also that the number carries a second-order harm: it is a false input to planning. Any downstream estimate that treats the declared budget as the expected cost is wrong by the breach margin, every time.

  Specific risks:
    - Baseline drift: per Vaughan, the effective budget is now the mean *actual* spend, and it will continue to rise, because each uneventful breach licenses the next. There is no restoring force.
    - Planning corruption: a declared number that never predicts actual spend poisons every capacity, scheduling and cost estimate built on it. The system believes something false about itself.
    - Boilerplate declarations: if the declaration is universal and consequence-free, its information content is zero. It cannot be used to distinguish a run that overran by 5% from one that overran by 500%.
    - No monitor: per the enforcement findings, disclosure without a resourced reader is not a control. If no agent or human reviews budget declarations with authority to act, the declaration is a write-only log.
    - False safety signal: the presence of a budget in the governance documentation will read to any reviewer — including future C2A2 self-review — as evidence that cost is controlled. It is evidence that cost was once considered.

  Mitigations available:
    - Make the breach cost something: hard stop, degraded mode, or mandatory escalation on overrun. Enforcement, not disclosure, is what the governance literature identifies as the binding element.
    - Re-fit the budget to observed spend. If every run breaches, the number is wrong; setting it correctly restores information content and makes genuine outliers visible again.
    - Two-tier limits: a soft target (declared, monitored, breachable) plus a hard ceiling (enforced). This is the standard resolution and preserves flexibility without letting the ceiling drift.
    - Publish the breach *margin distribution*, not the breach *fact*. A universal binary breach flag is uninformative; the distribution of overrun ratios is diagnostic and detects Vaughan-style drift as a trend.
    - Require a non-boilerplate, structured justification for large overruns only, so that the explanation channel is not saturated and can retain signal.
    - Appoint an actual reader with authority — the comply-or-explain literature's own prescription.

  STEELMAN:
    Item: PRESUMPTION-764
    Strongest counterargument: A budget can be a real constraint without being a hard limit. Its function may be to make cost *salient* rather than to cap it — a soft target that every run exceeds may still keep every run an order of magnitude cheaper than it would be with no target at all, and the counterfactual (no budget) is the comparison that matters, not the counterfactual (budget always respected). The comply-or-explain evidence is about firms with strong incentives to conceal from investors with weak incentives to look; a pipeline has no motive to obfuscate from itself, so the boilerplate mechanism may not transfer. And the Vaughan analogy is imperfect in an important way: at NASA the deviation concerned a safety margin where the tail outcome was catastrophic and irreversible. Overrunning a compute budget has a linear, recoverable, and immediately visible cost. Drift in a domain with linear costs and fast feedback is far less dangerous than drift in one with a catastrophic tail.
    What would need to be true for C2A2 to be safe: (a) The budget must be explicitly labelled a soft target, not a constraint, in every artefact that cites it — so that no downstream reasoning treats it as a cap; (b) the overrun distribution must be monitored and must be stationary, not trending — a stable 30% overrun is a mis-set target, a rising overrun is normalization of deviance; (c) a hard ceiling must exist somewhere with real enforcement, even if far above the soft target; (d) the cost of overrun must remain linear and recoverable — the argument collapses if any breach can trigger an irreversible outcome; (e) someone or something must actually read the declarations.
    How to test: Extract the declared budget and actual spend for every run over the available history and plot the overrun ratio as a time series. A flat series supports the steelman (mis-set but stable target); a rising series is direct empirical confirmation of normalization of deviance inside C2A2 and refutes the presumption outright. Second test: run a matched set of tasks with the budget declaration removed entirely and compare spend. If spend is unchanged, the budget is doing no work and the presumption is refuted; if spend rises materially, the soft target is functioning as the steelman claims. Third: audit whether any artefact or downstream calculation uses the declared budget as an estimate of actual cost — every such use is a live error today.
