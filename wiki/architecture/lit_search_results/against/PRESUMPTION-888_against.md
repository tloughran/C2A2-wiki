  Strength of challenge: Moderate

  Summary: The streetlight reading is not wrong, but it is incomplete, and the appraisal literature supplies
    the missing half. Where future uses are unknowable, observed use is a defensible proxy — not because it
    is accurate but because the alternatives (predict all future uses; appraise on intrinsic content) are
    worse-behaved. The profession has argued this since Schellenberg and has not settled it. What survives
    the challenge is a narrower and better claim than the presumption states: use-by-a-consumer is a
    legitimate proxy for value *when the consumer population is external to the thing being assessed*. It
    stops being legitimate when the only consumer is the assessing system's own instrument, because then the
    proxy is measuring the instrument's coverage and reporting it as the material's worth. That is the
    circularity the streetlight sources name, and it is the estate's actual configuration.

  Specific risks: Under a self-consuming proxy, material outside the instrument's reach is not judged
    low-value — it is never judged, and its absence from the value ranking is read as a low ranking. The
    reflexive effect compounds: what the instrument reads gets curated, gets richer, and reads better next
    time.

  Mitigations available: Name the consumer whenever value is asserted through use, and state whether it is
    internal or external. One line per assertion; it makes the circular cases visible without requiring a
    new theory of value.

  STEELMAN:
    Item: PRESUMPTION-888
    Strongest counterargument: There is no consumer-independent notion of value for a curation estate. A
      document nobody and nothing will ever read has no operative worth however good it is, and demanding
      that value be assessed "through content" is demanding an appraisal from nowhere. The instrument-bias
      objection assumes an outside standard that does not exist; what looks like circularity is just the
      only available measurement, honestly applied.
    What would need to be true for C2A2 to be safe: the consumer set would have to be plural, so that no
      single instrument's coverage determines the ranking, and material outside all consumers would have to
      be reported as *unassessed* rather than as low-value.
    How to test: take the material the current instrument does not read and ask whether anything in the
      estate's registers records it as unassessed. If it appears nowhere, the circularity is operative.
