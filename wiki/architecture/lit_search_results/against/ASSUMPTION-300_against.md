"The Chameleon's Limit: Investigating Persona Collapse and Homogenization in Large Language Models." arXiv 2604.24698, 2026. — Persona-seeded agents converge into a narrow behavioral mode ("persona collapse"); models retain only the most stereotypically salient persona attributes and discard the rest, producing homogenized populations.
    2. Hu, T. & Collier, N., 2024. "Quantifying the Persona Effect in LLM Simulations." ACL. — Persona variables explain little variance in simulated outputs; persona prompting moves behavior far less than assumed, undermining the premise that tradition-seeding produces genuinely distinct interlocutors.
    3. Cheng, M., Piccardi, T., Yang, D., 2023. "CoMPosT: Characterizing and Evaluating Caricature in LLM Simulations." EMNLP. — Persona simulations drift toward stereotype/caricature of the seeded identity; a "Levin agent" risks being a caricature of Levin, which inspection of the seed prompt does not reveal.
    4. Turing Institute/CETaS, 2025. "Patterns, Not People: Personality Structures in LLM-powered Persona Agents." — Persona agents exhibit shared underlying personality structure from the base model regardless of seeding; apparent inter-agent disagreement is generated by one substrate, unlike adversarially trained components with genuinely opposed objectives.
  Strength of challenge: Moderate
  Summary: The literature challenges both the adequacy and the superiority clauses. Persona collapse, weak persona effects, and caricature findings show tradition-seeded agents tend to be homogenized projections of one base model wearing thin masks — the functional opposite of GAN-style training, whose value lies in genuinely opposed optimization pressure producing adversarial refinement that neither component would generate alone. Seeded dialogue has no analogous pressure: both "sides" are the same model predicting plausible disagreement, so the dialogue explores what the base model thinks a Levin-Friston exchange sounds like, not what an actual adversarial process would discover. The inspectability argument is also weakened: what is inspectable is the seed prompt, not the behavior; caricature and collapse occur downstream of the inspectable layer.
  Specific risks: Deliverable substitution is weaker than promised while labeled "better"; dialogue outputs present base-model consensus dressed as multi-tradition agreement, inflating apparent convergence between traditions (compounding ASSUMPTION-294's independence problem); external reviewers familiar with the persona literature discount the result.
  Mitigations available: Cross-model seeding (different base models per tradition) to break substrate identity; caricature/individuation checks (CoMPosT-style) on agent outputs against real corpus text of each thinker; retrieval-grounding each agent in its tradition's actual texts rather than persona prompts alone; relabel the deliverable honestly as "inspectable multi-agent dialogue" rather than equivalent-or-better simulation.
  STEELMAN:
    Strongest counterargument: "GAN-simulated" was itself a loose promise — no actual GAN over philosophical traditions was buildable — so the comparison class is a metaphor, not a forfeited capability. Inspectability is a real evidential virtue: a transparent dialogue whose seeds, transcripts, and grounding can be audited supports stronger claims than an opaque adversarial process, and retrieval-grounded persona agents materially exceed the prompt-only setups the collapse studies test.
    What would need to be true for C2A2 to be safe: Agents are grounded in tradition corpora, not just persona prompts; outputs are validated against real texts of each tradition; claims of "better" are scoped to auditability, not to adversarial discovery power.
    How to test: Blind comparison — give experts agent-generated tradition statements mixed with real quotations; if experts cannot attribute agent outputs correctly or rate them as caricature, adequacy fails. Also measure inter-agent output similarity (embedding distance) against between-tradition distance in the real corpora.
