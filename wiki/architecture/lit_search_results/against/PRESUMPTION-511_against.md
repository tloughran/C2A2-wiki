  STEELMAN:
    Item: PRESUMPTION-511
    Strongest counterargument: There is no substantive case against this item; the strongest available counterargument is a matter of proportion rather than validity. Reproducibility in the NASEM sense is genuinely valuable even though it is not confirmation — it eliminates transcription errors, nondeterminism, environment drift, and undocumented manual steps, which together account for a large share of real-world measurement defects and are cheap to rule out. A framing that dismisses reproduction as merely confirming determinism risks discouraging a practice that is worth keeping. The more consequential caution runs the other way and makes the item harder, not weaker: the remedy it implies — obtain a second method — may not deliver what it promises. Work on failure independence in generated code finds that structurally varied implementations still fail on the same inputs, with majority-voting reliability gains falling below half the theoretical independent-case gains. So building a second counter, a second detector or a second judge does not automatically buy independence, particularly where both inherit the same corpus, the same definitions or the same model. The honest version of the item is therefore stronger than stated: reproduction confirms determinism, a second method confirms less than it appears to, and independence has to be engineered and then measured rather than asserted from the existence of two artifacts.
    What would need to be true for C2A2 to be safe: That the vault distinguishes reproduced from replicated in its language, and that any claimed second method has its shared components recorded so its actual independence can be judged.
    How to test: Run the item's proposed sweep — for each standing verification figure, ask whether a second method exists, and count the single-method figures. Then for each figure that does have a second method, record the four shared components (code path, corpus, model, execution context). Figures where all four are shared should be reclassified as single-method.
