  Strength of challenge: Moderate

  Summary: No source contradicts the facts reported. What the literature challenges is their interpretation. First, parser divergence over long-lived heterogeneous records is the measured norm in the log-parsing field, where refined-metric template accuracy for state-of-the-art parsers averages around 0.2; three parses returning three figures is therefore unremarkable and the finding's force comes from the queue never having been benchmarked, not from an unusual failure. Second, the item places the defect in the reader — a parser that "misses" a format — whereas the robustness-principle critique argues that reader tolerance is the mechanism by which format drift becomes permanent, so the corrective the item implies would worsen the condition it names. Third, the strongest limb, that depth "has never been a measured quantity", conflates history with possibility: Little's Law recovers depth from arrival and residence data already in the file, and automated schema-induction work shows that a consistent count over heterogeneous records is obtainable without any governance decision. The residual, unchallenged, and genuinely serious core is that thirteen items existed outside every count — an absence-of-evidence figure that is a lower bound, since it was produced by the same instrument family that missed them.

  Specific risks:
    - Misattributed defect: fixing the parser instead of the write path would, per Thomson, entrench the drift and make the next hidden format harder to find, not easier.
    - Governance overreach: the item concludes that reconciliation "requires a format decision no agent may make." If that conclusion is wrong — and the schema-induction literature suggests it is — then the queue stays unreconciled for a reason that is procedural rather than technical, and the standing 163/26/13 divergence persists indefinitely by choice.
    - False precision on "thirteen": the count of hidden items was produced by a search that did not know what it was looking for. It is a floor. Treating 13 as the size of the gap risks a second discovery of the same kind.
    - Unmeasurability as a self-fulfilling claim: asserting that depth has never been measurable removes the incentive to estimate it by the indirect route that is available.

  Mitigations available:
    - Estimate L indirectly from filing timestamps and search tags before attempting any format decision. This is a measurement no schema change is needed for and it produces a fourth figure that can adjudicate among the existing three.
    - Move validation to the write path: reject non-conforming appends at filing time rather than tolerating them at read time. This is the direct implication of the robustness-principle critique and it is the only remedy that stops the next drift.
    - Run automated schema induction over the existing file to enumerate the *distinct record shapes actually present*, rather than counting items under one assumed shape. This converts "thirteen hidden items" from a discovery into an inventory.
    - Report the backlog as an interval with a stated parse, not as a scalar. Three figures from three parses is only a problem if the system is committed to a scalar.

  STEELMAN:
    Item: ASSUMPTION-1149
    Strongest counterargument: The item mistakes a normal condition for a discovery and then draws a governance conclusion from it. Every long-lived heterogeneous log drifts, every regex-defined reader diverges from every other, and the published state of the art on this exact problem gets template accuracy around 0.2 on curated benchmarks — so a hand-written queue parser missing a variant format is the expected outcome, not a surprise. Having correctly observed the drift, the item then locates the fault in the parser, which is precisely the move the robustness-principle critique identifies as the cause of protocol decay: each accommodation the reader makes removes a degree of freedom from the writer forever. Finally, the claim that depth "has never been a measured quantity" is an overreach that licenses inaction. Depth is derivable from arrival and residence data the file already carries, and the conclusion that reconciliation requires an unauthorised format decision therefore rests on an unnecessary premise.
    What would need to be true for C2A2 to be safe: (a) The indirect Little's-Law estimate would have to be either unavailable — no reliable filing or completion timestamps — or so wide as to be useless; (b) the thirteen items would have to be the only hidden ones, i.e. the discovery instrument would have to have had full coverage of format space, which nothing in the item establishes; (c) the writers into the queue would have to be unmodifiable, so that reader-side tolerance really is the only available lever; (d) there would have to be no automated way to enumerate distinct record shapes in the file, which the schema-induction literature contradicts.
    How to test: Three cheap measurements, none requiring a format decision. (1) Enumerate distinct record shapes in `for_lit_search.md` by clustering lines mechanically rather than by matching an assumed pattern; compare the cluster count to the number of formats the current parser knows about. If it exceeds it, there are further hidden items and 13 is a floor. (2) Compute L from λ and W using existing timestamps and compare against the three parse-derived figures; if the indirect estimate lands outside all three, all three parses are wrong in the same direction. (3) Insert a deliberately malformed canary record and measure how many downstream consumers count it. This measures reader tolerance directly and tells you whether the drift path is still open.
