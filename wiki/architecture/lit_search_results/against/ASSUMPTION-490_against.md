Which of the two regimes obtains here is undetermined and is the pivotal question the item does not ask.

LCA recovers accuracy for each method without a reference standard, but requires either conditional independence between methods or explicit modelling of their dependence.   Strength of challenge: Moderate
  Summary: The observation — three readings, one quantity, one week, a decision explicitly resting on the answer — is not challenged and is a legitimate finding. What is challenged is the item's implicit request for an arbitration rule that names an authoritative instrument. The measurement-comparison literature is clear that where no external reference exists, you do not arbitrate; you characterise systematic difference and limits of agreement, and you treat the disagreement as a property of the pair rather than a fault in one member. The methods that do recover per-instrument accuracy without a reference (latent class analysis) require conditional independence between the instruments or explicit modelling of their dependence — and three counters sharing a codebase, a corpus and a definition of "word" are strongly dependent, so the precondition fails. There is, however, a way out that the item nearly reaches: unlike a clinical assay, a word count over a frozen snapshot with a stated Notes-stripping rule is deterministic and can be made exact. If a reference definition is written down, this stops being a no-gold-standard problem and becomes an ordinary specification problem. The disagreement is then almost certainly definitional, not instrumental — three correct implementations of three different unstated definitions.
  Specific risks: An arbitration rule is adopted that declares one counter authoritative on grounds other than a written definition (seniority, recency, convenience), and tier calibration is then set against a number that was chosen rather than established — with the disagreement preserved inside a decision that now looks settled. Second risk: the 0.77x under-run is treated as a measurement dispute when the declared length_actual_words figure is a separate and more serious problem, since a declared value that does not match any of the three measured values is not a third reading but an unsourced assertion.
  Mitigations available: Write the definition before choosing the instrument: state exactly what counts as a word, what Notes-stripping removes, and what boundary conditions apply, then re-derive all three counts over one frozen snapshot per the item's own test. Expect the three to converge; where they do not, the residual is a genuine implementation bug and is now localisable. If they cannot be made to converge, report a Bland-Altman-style bias and limits of agreement rather than a winner, and propagate the interval into tier calibration rather than a point value. Treat the inflated declared length_actual_words as a separate defect with its own root cause — a declared figure is not an instrument.

    Strongest counterargument: The item asks for an arbitration rule and the measurement literature's answer is that arbitration is the wrong move. Where no external reference standard exists, method comparison is explicitly not a calibration problem: the recommended output is a characterisation of systematic difference and limits of agreement between the methods, not a ruling that one is correct. The techniques that do recover per-instrument accuracy without a gold standard — latent class analysis — require either conditional independence between the instruments or explicit modelling of their dependence, and three counters built in the same codebase over the same corpus with the same inherited assumptions about tokenisation are about as conditionally dependent as instruments get, so the precondition fails outright. Naming one counter authoritative would therefore be a decision dressed as a finding, and tier calibration would inherit it. But the deeper point is that this need not be a no-gold-standard problem at all. A word count over a frozen snapshot is deterministic, and the reason there is no reference is simply that nobody has written the definition down. Almost certainly all three counters are correct implementations of three different unstated definitions of "word" and of what Notes-stripping removes, in which case the dispute is definitional, the arbitration question dissolves, and the fix is a specification rather than a ruling.
    What would need to be true for C2A2 to be safe: That a written counting definition exists before any tier-calibration decision is taken, and that if the three counts still disagree afterwards, an interval rather than a point value propagates into the decision.
    How to test: Run the item's own test with one addition. Freeze a snapshot, write the counting definition explicitly, re-derive all three counts against it, and record the residuals. Convergence proves the dispute was definitional. Persistent divergence localises a real implementation bug — and in that case report bias and limits of agreement, not a winner. Separately, trace where the declared length_actual_words figure originates; if it matches none of the three re-derived counts, it is not a measurement and should not be in the comparison.
