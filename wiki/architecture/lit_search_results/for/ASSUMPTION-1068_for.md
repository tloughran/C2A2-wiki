  Summary: The corrective converse is well supported and essentially uncontroversial in the practice literature: a monitoring component that shares infrastructure with what it monitors is not an independent channel, its failure presents as silence rather than as an alarm, and this is the standard motivating example for meta-monitoring. The field's answer to "who watches the watcher" is not another watcher but an inversion of the signal direction plus a change of location — the job emits a periodic affirmative ping to a RECEIVER HOSTED OUTSIDE the failure domain, and the receiver alarms on the ping's absence. The regress terminates there because the outermost element performs no work and so cannot fail in the same manner as the things it observes; it only waits and times out. That is the precise architectural gap in 14a's case: `morning-system-health` correctly encodes "missing equals FAIL" as a rule, but the rule can only be EVALUATED by the run that died, so the fleet's most explicit anti-presumption rule is unreachable in exactly the state it was written for. **The item's most valuable content is the number it quotes rather than the principle it restates. A detector drawn from a population with a measured 35.5% non-completion rate cannot have more than about 64.5% availability against an independent fault and has strictly less against a correlated one — which converts PREMISE-110's qualitative scope guard into a computable bound on this specific fleet's monitoring coverage, using a figure already recorded in the task file.**
