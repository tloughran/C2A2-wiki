  Sources:
    1. Wegner, Giuliano & Hertel, 1985; Wegner, 1987. "Transactive Memory: A Contemporary Analysis of the Group Mind." in Mullen & Goethals (eds.), Theories of Group Behaviour. Springer. — Foundational transactive memory theory establishes that externalized knowledge stores function as valid memory substitutes. Individuals routinely encode knowledge externally in diaries and documents, and retrieval from these external stores is functionally equivalent to internal recall. This directly supports treating written vault entries as recoverable prior thought.

    2. Argote & Ren, 2012. "Transactive Memory Systems: A Microfoundation of Dynamic Capabilities." Journal of Management Studies (Carlson School). — Extends transactive memory to organisational settings, showing that knowledge stored in external repositories (including digital systems) supports team performance comparably to internally-held expertise, provided the meta-knowledge (knowing what is stored where) is maintained. The vault-as-external-memory analogy maps directly.

    3. Stein, 1995. "Organizational Memory: Concepts and Applications." Organizational Memory information systems literature (ScienceDirect). — Documents that well-structured knowledge repositories substantially improve retrieval fidelity compared to informal memory, though retrieval quality is heavily dependent on indexing quality and search design. This supports the operational validity of vault retrieval while flagging the indexing dependency.

  Strength of support: Moderate

  Summary: The transactive memory literature robustly supports the principle that written/externalized knowledge bases function as valid memory substitutes and that retrieval from them is a legitimate epistemic act. The claim that unwritten material is treated as nonexistent is consistent with how transactive memory systems operate by design — the system only surfaces what was encoded. The literature also confirms that retrieval completeness is heavily dependent on documentation completeness and retrieval mechanism quality, meaning the claim is valid in structure but its performance depends on vault coverage. The assumption elides the incompleteness problem: the vault is unlikely to cover all relevant prior thought, so some material is not nonexistent but merely unrecorded.

  Caveats: The organisational memory literature specifically identifies that "attempts to build organizational memory systems have generally failed because they required additional documentation effort with no clear short-term benefit" and that "much organizational knowledge never makes it into such systems in the first place." The claim's validity is therefore contingent on the vault's actual coverage rate, which is not empirically established in the C2A2 context. The treatment of unwritten material as nonexistent is operationally defensible but epistemically aggressive — it forecloses retrieval of tacit or undocumented knowledge that genuinely exists.
