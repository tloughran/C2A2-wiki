  Sources:
    1. Mateen, F. J. et al., 2013. "Titles versus titles and abstracts for initial screening of articles for systematic reviews." Clinical Epidemiology 5 (doi 10.2147/CLEP.S43118; PMC3604876) [search-result; author/title from background-knowledge]: A titles-first screen rejected 86% of records on title alone and still reached 100% recall of the 13 finally included studies, the same recall as title+abstract screening. Precision was lower (3.2% vs 7.1%). This is the closest direct analogue: titles can carry enough signal for high-recall *exclusion*. The paper itself notes there is no consensus on title-only screening.
    2. Header-only vs header+body email classification study, IJICT (ijict.iaescore.com, article 21627) [search-result; authors not verified]: Header-only features (which include the subject) gave classification accuracy comparable to full content (>95% with RF/XGBoost/LightGBM), with lower processing time. This is analogous support that metadata can approximate content-based classification for some tasks.
    3. Practitioner email-triage implementations, e.g. Nylas cookbook [search-result]: Report >90% accuracy using sender + subject + a 200-character snippet. This is weak, non-peer-reviewed support, and it still uses a content snippet, not the title alone.

  Strength of support: Weak

  Summary: Information-retrieval and evidence-synthesis practice gives some precedent for metadata-first triage. In one systematic-review comparison, title-only screening lost no included studies. Header-based email classification can rival full-content classification in reported accuracy. This supports the general idea that short descriptive metadata can be an informative filter. None of the sources supports the title being the *sole* filter for a semantically subtle property such as "carries designer input". None addresses chat titles, which are often auto-generated by the platform from the first message rather than written by the author to describe content.

  Caveats: (a) In the review literature, title screening is a first pass followed by abstract or full-text review. It is not a sole inclusion filter. (b) Header-only email accuracy concerns coarse classes (e.g. spam or phishing) with strong sender signals. (c) Auto-generated chat titles summarise the opening turn, so designer input arriving later in a chat would not be reflected. This is a selection-bias risk outside the scope of supportive search. (d) Recall at 13 included items is a small-sample result.

  Search scope: preliminary (2 searches, 0 fetches): systematic-review title screening, email header vs body classification. Not searched: chat/conversation title generation quality, metadata-based sampling bias in corpus construction.

  Recommendation: PARTIALLY-SUPPORTED (titles are an informative first-pass signal by analogy; no support for sole-filter use on chat titles)
