  Sources:
    1. Manski, C.F., 2003. Partial Identification of Probability Distributions (and CAE WP #05-10). — The foundational statement of the position the item argues for: when point identification fails, the correct report is the identification region (worst-case bounds), progressively narrowed by explicitly stated assumptions. "The data alone" always support SOME interval; reporting nothing is not the only alternative to a point estimate.
    2. Horowitz, J. & Manski, C., 1998/2000. Interval estimates covering the identification region. — Supplies the inferential machinery: confidence intervals that account for sampling variation in the estimated bounds, so a bounded report is defensible, not hand-waving.
    3. Tamer, E. "Partial Identification in Econometrics" (Annual Review / Palgrave chapter). — Review-level confirmation that partial identification is an established, mainstream practice with a bottom-up discipline: worst-case bounds first, then stated assumptions that narrow them.
    4. Standard finite-population sampling (Cochran, Sampling Techniques): a stratified hand sample of the 209 partials yields a proportion estimate with a computable interval. — Directly matches the item's own named settling quantity and confirms the population being fully enumerated is exactly the condition under which sampling is straightforward.

  Strength of support: Strong

  Summary: The literature supports the item's claim as close to a settled methodological norm. Partial identification is a developed research programme built on the premise that failure of point identification does not license silence: worst-case bounds are always available and are narrowed by assumptions stated as such. Horowitz and Manski supply interval estimators that carry sampling uncertainty, so the bounded report is fully inferential rather than an informal hedge. In this specific case the support is stronger than in the general theory, because the population (209 partials) is fully enumerated — the missing element is only classification, which is exactly the case classical stratified sampling is designed for; a hand sample of modest size yields a proportion with a stated interval. Support is for the METHODOLOGICAL claim (an interval should be reported) rather than for any particular number.

  Caveats: (1) Partial identification addresses non-identification arising from missing data or weak assumptions; here the obstruction is measurement cost (automation failed), which is a different source — the transfer is to the reporting norm, not to the identification theory. (2) The item's premise that "the register has no representation for between X and Y" is an internal fact; the literature says nothing about whether adding an interval type to this register is safe, and the 07-31 disposition (REVISE-254) already flagged three-state intake conventions as needing a measured basis. (3) Estimating a defect fraction by hand sample introduces classifier subjectivity that automation would not have; no inter-rater reliability provision is named in the item. (4) Search scope: partial identification, bounds analysis, interval estimation, finite-population sampling. NOT searched: audit-sampling standards (AICPA AU-C 530 / ISA 530), which are the closest professional analogue and should be searched before any convention is minted.
