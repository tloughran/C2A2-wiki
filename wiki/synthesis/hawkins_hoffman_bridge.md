## The thalamus as an interface: a mechanistic address for manufactured structure
*Sewing Agent, 2026-08-02*

**Orphaned page:** `inbox/proposals/pending/2026-07-28_hawkins_heterarchy-thalamic-transform-explainer.md` (PROP-2026-07-28-001). This bridge file did not previously exist.

**Why it sits at this intersection.** The Thousand Brains Project's plain-language explainer proposes that the thalamus is not a relay but a reference-frame transformer: it converts egocentric sensory coordinates into object-centric ones before the signal reaches cortex, with cortico-thalamic feedback specifying which transform to apply. Hoffman's interface theory claims that perceived structure is constructed by the perceiving apparatus rather than read off the world. The object-centric reference frame is a clean instance: it is demonstrably not present in the retinal or tactile input, and the theory now names the anatomy that manufactures it.

**Synthesis claim.** Interface theory has been long on argument and short on mechanism; the Hawkins proposal supplies a mechanism at exactly the right grain. "The brain translates on the fly" is interface construction with an anatomical address and a falsifiable prediction attached — thalamic activity should covary with cortically-inferred object identity and pose, not with sensory input alone. If that prediction holds, it is the most concrete evidence in the wiki that a perceptual frame is manufactured rather than received.

**The asymmetry worth recording.** Hawkins takes the manufactured frame to be *tracking* a real object with a real pose — the transform is a good one because there is something it is a transform of. Hoffman takes the manufacturing to go all the way down: fitness-beats-truth implies no reason to expect the constructed frame to correspond to anything. So the two agree that structure is constructed and disagree about whether construction is *veridical construction*. That is the same divergence-atop-agreement shape that governs Hoffman's relation to Carroll on spacetime, appearing here at the scale of a single cortical column.

**Open question the wiki cannot yet answer.** If the thalamic transform were experimentally confirmed, would it count as evidence *for* interface theory or merely *compatible* with it? Hawkins's version predicts the transform is well-adapted to object structure; Hoffman's predicts only that it is well-adapted to fitness. The wiki has no experiment that separates those, and until it does, the mechanism is shared while the interpretation is not.

### 2026-08-23 — Selective non-veridicality is not the same claim as total non-veridicality

*Sewing Agent, 2026-08-23.* **Orphaned pages:** [[2026-08-18_hawkins_tbs-plain-language-explainer]] (PROP-2026-08-18-001) and [[2026-08-17_hawkins_grid-place-cells-reference-frames]] (PROP-2026-08-17-012).

**Why they sit at this intersection.** The vault already records that Monty's models are non-veridical in the interface-theoretic sense — structured for interaction, evaluated by predictive utility, not pictures of the world. The explainer adds a wrinkle that cuts the other way and the proposal flags it honestly: Monty's emergent shape bias tracks **morphology**, a mind-independent geometric property, and its symmetry inferences are validated by low Chamfer distance against ground truth. The grid-cell session pushes from the other side: location coding is anchored to *distal environmental cues chosen by the organism*, so the frame is constructed — but constructed to track something.

**Synthesis claim.** Hawkins' non-veridicality is **selective**: the interface discards colour and surface texture while remaining anchored to real geometry, and the program's own success criterion is agreement with ground-truth pose. Hoffman's is **total**: there is no veridical state to fall back to, and Fitness-Beats-Truth denies that fitness-tuned perception tracks any mind-independent structure at all. These have been treated in this vault as the same "perception is not a picture" claim. They are not. Selective non-veridicality is a claim about *compression* — the interface drops what does not pay — and is fully compatible with realism about the retained dimensions. Total non-veridicality denies there are retained dimensions in that sense.

**Open question the wiki cannot yet answer.** Is selective non-veridicality a coherent position on Hoffman's account, or does anchoring to ground-truth geometry collapse it into realism about geometry? There is a sharp version: Monty is *scored* against ground truth, so its designers are committed to a veridical geometric fact of the matter, whatever they say about colour. If Hoffman's theorem applies, that scoring criterion should be evolutionarily unstable — a fitness-tuned system should be driven away from Chamfer-optimal pose estimation. Whether it is, is checkable in simulation and nobody has run it. Every existing convergence entry between these two traditions should be re-read against this distinction before it is cited again.
