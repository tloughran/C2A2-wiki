Integration path

What is integrated now

  • Community Education tab carries this Heartbeat chapter as an Education Tools sub-tab.
  • Karpathy-style raw source -> compiled wiki -> schema model is documented.
  • Multi-community federation, privacy, and permission model is captured.
  • Pulse metrics and signals load from a static digest snapshot with an embedded fallback.
  • Each reader sets a preference lens (sources, tags, relevance, ranking); magic-link sign-in syncs it across devices.

Next engineering slice

  • Export live /api/digest JSON into data/digest.json on a schedule.
  • Add authenticated admin path for per-community source profiles.
  • Promote reviewed answers into markdown wiki pages with citations.
  • Define selective contribution API for stars, comments, and rankings.
