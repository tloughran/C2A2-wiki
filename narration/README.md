# C2A2 Narration (modular)

Modular rebuild of `wiki_narration.html`. Same visual tool, split into files
so it's readable, testable, and extensible. Runs as a Vite project for
development; builds to a static `dist/` folder for distribution.

## Layout

```
narration/
├── index.html               # thin shell, IDs only
├── src/
│   ├── main.js              # entry — loads data, wires modules
│   ├── state.js             # central state, subscribe/setState
│   ├── graph.js             # D3 force graph, drag, zoom, highlight
│   ├── narration.js         # tour logic, sync, Brief/Deep
│   ├── tts.js               # browser + OpenAI speech, visible errors
│   ├── ui.js                # header, footer, settings modal, detail panel
│   ├── toast.js             # transient notifications
│   └── styles.css
├── data/                    # loaded at runtime, regenerated by build_data.py
│   ├── nodes.json
│   ├── links.json
│   ├── narrations.json      # date → {brief, deep, voice}
│   └── metadata.json
├── tools/
│   └── build_data.py        # scan wiki/ → data/*.json
├── package.json
├── vite.config.js
└── README.md
```

## First-time setup

```bash
cd narration
npm install
```

This installs D3 and Vite. One-time; rerun only when `package.json` changes.

## Development

```bash
npm run dev
```

Starts Vite on `http://localhost:5173` with hot reload. Edit any file in
`src/` and the page updates immediately. Open DevTools (Cmd+Opt+J) — every
TTS error surfaces as a toast AND a console log, so nothing dies silently.

## Regenerating the data from the wiki

Whenever the wiki content changes and you want the visualization to reflect
it, regenerate the data layer:

```bash
npm run data            # shorthand for: python3 tools/build_data.py
```

Narrations are **preserved by default** — existing entries in
`data/narrations.json` are kept as-is; only dates with no entry get a
generated fallback. This protects any hand-written or richer AI-generated
narration content across rebuilds.

To start fresh:

```bash
python3 tools/build_data.py --overwrite-narrations
```

## Production build

```bash
npm run build
```

Produces `dist/` — a static folder with a minified bundle. Open
`dist/index.html` directly (file://) or drop the folder on any static host.
Data is loaded via relative paths, so the folder is self-contained and
portable.

## Extending

Each module has one concern and one clear public surface:

- **Adding a new tour mode:** edit `src/narration.js::startTour` to accept
  a new string and set the appropriate first index.
- **Swapping the TTS provider:** add a new backend function in `src/tts.js`
  next to `speakOpenAI`, and extend the dropdown in `index.html` +
  `ui.js::updateProviderUI`.
- **Changing the graph layout:** all D3 wiring is in `src/graph.js`. The
  data loading is separate.
- **Persisting more settings:** add the key to `PERSIST_KEYS` in
  `src/state.js`.

## Known differences from `wiki_narration.html`

- Recording (MediaRecorder-based video capture) is not yet ported —
  shows a toast if the user clicks Record.
- Chat input is scaffolded in the UI but not wired to any backend.
- Narrations preserved on rebuild: the old in-memory generator ran fresh
  every time; the modular script respects manually curated narration entries.
